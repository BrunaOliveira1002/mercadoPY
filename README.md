# 🛒 MercadoPy

Projeto desenvolvido em Python com o objetivo de praticar conceitos fundamentais da linguagem e Programação Orientada a Objetos (POO).

O MercadoPy simula operações básicas de um mercado, permitindo trabalhar com produtos e um carrinho de compras através do terminal.

## 🚀 Funcionalidades

- Cadastro e identificação de produtos
- Código automático para cada produto
- Exibição de nome e preço
- Adição de produtos ao carrinho
- Controle de quantidade dos produtos
- Visualização do carrinho
- Cálculo do valor total da compra
- Formatação de valores em moeda
- Finalização do pedido

## 🧠 Conceitos praticados

Durante o desenvolvimento foram utilizados conceitos como:

- Programação Orientada a Objetos (POO)
- Classes e objetos
- Encapsulamento
- `@property`
- Funções
- Type hints
- Listas e dicionários
- Estruturas condicionais
- Laços de repetição
- Organização do código em módulos e pacotes
- Importação de módulos
